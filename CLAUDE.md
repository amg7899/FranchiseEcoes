# FRANCHISE ECOES website

Static site (plain HTML + CSS + a little JS, no build step) for ECOES Franchise, the mobile EV-charging franchise of ECOES JV, split off from the ECOES JV site (https://ecoes.eu/, repo amg7899/SUM) at the client's request on 2026-10-15. Content source: the client's visualisation PDF "ECOES Franchise – визуализация на сайта" v5 (2026-11-03, 21 pages; made in this session from the client's PDF and the MultiCharger Box Word file) – texts, images, page structure. Published by GitHub Pages from `main` (root) at **https://franchise.ecoes.eu/** (custom domain since 2026-11-06; https://amg7899.github.io/FranchiseEcoes/ redirects there; every push deploys in about a minute). DNS at SuperHosting: CNAME franchise → amg7899.github.io only (no A/AAAA for the subdomain; the client e-mailed SuperHosting from the account's contact e-mail, in Bulgarian, as for ecoes.eu); GitHub shows "DNS check successful" and Enforce HTTPS is on. The `CNAME` file (`franchise.ecoes.eu`) at the root is GitHub's: keep it, and pull before pushing when the client changes Pages settings. Every page carries `rel=canonical` (itself), hreflang alternates en / bg / x-default and Open Graph tags (og:image = `assets/img/og-image.jpg`, 1200 × 630) with absolute https://franchise.ecoes.eu/ URLs; `sitemap.xml` + `robots.txt` list the 12 pages; a new page needs all of them. `404.html` links to `/`. Still to do: a test message from a form on franchise.ecoes.eu, so FormSubmit asks sales@ecoes.eu for activation. Repo is public.

## Working with the client
- The client writes in Bulgarian (sometimes English); answer in the language of their message.
- Use the client's text verbatim. Do not add copy, taglines or sections. Fix only obvious typos, and report every fix. When unsure, ask.
- After every change: commit, push to `main`, and send the live link plus screenshots.
- After every change to a CSS or JS file run `python3 tools/bust.py` before committing: every page links its CSS/JS with `?v=<hash>` (GitHub Pages lets browsers keep files for 10 minutes and a normal reload does not re-check them, so without it the client saw the old layout after a deploy, 2026-11-04). New pages need the same `?v=` links (the script adds them).
- The client chose (2026-11-03): English + Bulgarian, static site like ecoes.eu (edits through Claude), the design left to us ("choose the best"). Brief: professional, modern, futuristic but true to the subject, clean, trustworthy, not looking AI-made; transparent containers with visible motifs; the strongest points on Home as linked containers, each with a "get offer" link to the contact form (as on ecoes.eu); only the logo is the same as ecoes. Changed 2026-11-05 (Preslav: "I don't want 'Get an offer' or 'Learn more' under every slogan and text", "more sequence"): the offer cards and the nine Why panes are whole-card links (the heading is the link, `.card-link::after` covers the card, an arrow chip `.go-chip--card` shows it), no text link pairs; the profit and certification intros on Home carry none; "Get an offer" stays in the header, the page heads, the Franchise closing band and once on each product page (after the investment comparison), and the forms close the pages. ## Languages (English + Bulgarian)

- Names stay in Latin and carry `translate="no"` (ECOES Franchise, ECOES MultiCharger, ECOES MultiCharger Box, ECOES JV, company names, addresses, e-mails, phones), with neighbouring spaces inside the span.
- `main.js`: the language switch keeps `?query#hash`; a language chosen with the switch is remembered in this browser (localStorage `ecoes-franchise-lang`, sessionStorage as fallback), always wins and marks its pages `translate="no"`; when the browser translates into a language the site has, it goes to our page instead. Automatic language (client, 2026-11-04: foreigners should get English): on the first arrival from outside the site (referrer empty or another host), the first of `navigator.languages` that the site has, otherwise English; so a foreign visitor on a `bg/` link lands on the English page (and the browser offers its own translation), a Bulgarian browser on an English link gets `bg/`. Robots (user agent with bot/crawl/spider/slurp/preview/lighthouse/headless) are never redirected, so both languages stay indexable and the Playwright scripts (HeadlessChrome) see the page they open; to test the redirect, use a normal Chrome user agent and a `locale`.
